      Nuancier et détection automatique

      Avec un nuancier, chaque couleur reçoit le code et le nom du fabricant le plus proche (ex. Artkal C15).

      Plus bas : sépare mieux les teintes proches. Plus haut : regroupe les compartiments mal éclairés.

        Touchez un cadre ou une ligne pour la repérer. Tracez un rectangle sur la photo pour ajouter une couleur oubliée ; remplace le cadre d’une couleur.

        Couleurs

        Le code (1 à 5 caractères, ex. J0, O1, 12) est écrit dans chaque perle de l’export. La valeur hexadécimale est la teinte mesurée : vous pouvez la corriger ou saisir celle publiée par le fabricant.

          Ajouter une liste de couleurs

          Une couleur par ligne : code, nom, puis la teinte en hexadécimal. Exemple : J0 Jaune clair #FCEB8B

            Sur l’écran bêta

            Caler l’écran sur la plaque

            1. Choisissez ci-dessous la plaque que vous posez, puis posez-la dans le coin éclairé, en butée contre la coque si elle dépasse.
            2. Avec les flèches, amenez le cercle vert sous le picot du coin.
            3. Avec + et −, amenez le cercle jaune sous le dernier picot de la rangée.
            4. Vérifiez que le cercle bleu tombe sous le dernier picot de la colonne, puis validez.

            Placer le motif sur la plaque

            Les petits points gris sont les picots libres. Déplacez le motif avec les flèches, d’un picot à la fois, ou faites-le glisser.
