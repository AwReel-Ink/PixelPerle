    Avec un nuancier, chaque couleur reçoit le code et le nom du fabricant le plus proche (ex. Artkal C15).

    Plus bas : sépare mieux les teintes proches. Plus haut : regroupe les compartiments mal éclairés.

      Couleurs

      Le code (1 à 5 caractères, ex. J0, O1, 12) est écrit dans chaque perle de l’export. La valeur hexadécimale est la teinte mesurée : vous pouvez la corriger ou saisir celle publiée par le fabricant.

        Ajouter une liste de couleurs

        Une couleur par ligne : code, nom, puis la teinte en hexadécimal. Exemple : J0 Jaune clair #FCEB8B

        Image

        Placez l’image sur vos plaques. Faites-la glisser, et utilisez les coins pour l’agrandir sans la déformer.

        Réglages de l’image

        Conversion

        Tous les rendus, de 0 à 100 % de tramage, sont calculés en même temps et affichés côte à côte : écartez ceux qui ne vous plaisent pas, puis validez votre préféré. Couleurs max. : 0 = toute la palette.

        Le meilleur rendu d’un coup, avec vos couleurs : contraste ajusté, 10 à 18 couleurs bien choisies, tramage dosé automatiquement, perles isolées nettoyées.

        Retouche

        Plaques

          Pose guidée

          Posez la plaque transparente directement sur l’écran de la tablette : l’écran devient le modèle, à taille réelle, couleur par couleur ou ligne par ligne.

          Lancez d’abord la Conversion depuis l’onglet Image.

          Comment ça marche

          1. Calibrez une fois l’écran avec une carte bancaire, puis avec la plaque elle-même.
          2. Posez la plaque : le liseré blanc doit dépasser régulièrement tout autour.
          3. Verrouillez l’écran pour que vos doigts et la pince ne déplacent rien.
          4. Posez les perles de la couleur en surbrillance, puis passez à la suivante.

          Votre avancement (couleurs posées, ligne en cours) est enregistré avec le projet.

          Les plaques ou l’image ont changé depuis la conversion.
